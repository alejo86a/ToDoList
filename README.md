# ToDoList

A minimal AngularJS starter/scaffold for a to-do list application.

## What it does

Currently just a skeleton: a single AngularJS app/controller (`ToDoController` in the `ToDoList` module) that renders a simple interpolated greeting (`{{"hola "+nombre}}`). No actual to-do list functionality (adding/removing items) has been implemented yet.

## Tech stack

- AngularJS 1.3.x
- Plain HTML/JavaScript, no build tooling or package manager

## Running it

Static front-end project — serve the folder with any static server and open `index.html`:

```bash
npx serve .
```

## Context

Early-stage personal practice exercise / scaffold for learning AngularJS, left unfinished at the "hello world" stage rather than a complete to-do list app.
